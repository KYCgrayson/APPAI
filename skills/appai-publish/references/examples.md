# Adapting examples

Choose a current example through [Pages](https://appai.info/spec/pages), `GET /api/v1/presets`, or the [overview's example links](https://appai.info/spec#publish-in-one-minute) at `/spec/examples/*.example.json`. The [company-service example](https://appai.info/spec/examples/company-service.example.json) is one starting point. Use [llms-full.txt](https://appai.info/llms-full.txt) when a single-file specification is needed.

Treat examples as structure, not evidence about the user's product. Replace demo copy, logos, destinations and claims; remove sections for which the user has no supporting facts. Validate the adapted body before publishing.
