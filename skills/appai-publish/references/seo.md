# SEO judgment

Read [Pages](https://appai.info/spec/pages) for metadata and canonical URL behavior, and [Multi-language & multi-page](https://appai.info/spec/i18n) for locale handling.

Decide which site is the product's primary home before setting a canonical override. Write titles and descriptions that distinguish the product and accurately describe the page. Use relevant real images for sharing; do not treat a canonical override as an access-control or privacy mechanism.

Write `metaDescription` per locale (≤500 characters); it falls back to `tagline` when omitted.
